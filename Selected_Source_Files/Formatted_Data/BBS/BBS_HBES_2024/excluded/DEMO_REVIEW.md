# BBS HBES 2024 Demo Grouping

This `demo` folder is a small test of the grouped-row approach for Google Sheets.

## Why this is cleaner

- One row per page would make the workbook too noisy.
- Grouping by chapter or annex table numbering keeps related pages together.
- The workbook keeps `Drive Link` blank so links can be pasted later without changing the structure.
- Local demo folders let you inspect the copied page images before deciding whether the grouping logic feels right.

## Suggested judgment

- If the grouped rows feel easy to explain in class, this is the better final direction.
- If a group still feels too broad, split it by subsection rather than falling back to one-row-per-page.
- The annex section benefits most from grouping because the table numbering already creates natural clusters.
