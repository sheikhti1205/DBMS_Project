# Keep vs Removed Demo

This demo splits the original grouped BBS HBES set into:

- `keep/` for groups that are more clearly environment-related
- `removed/` for groups that are weak fits or likely to be challenged

## Kept

- waste management
- environmental awareness
- annex domestic waste and mosquito
- annex awareness and disaster

## Removed

- key findings summary
- sample allocation / methodology
- household structure
- sanitation
- drinking water
- environmental protection
- annex waste management
- annex hazardous waste
- fuel-only weak groups
- income / occupation
- annex water-use
- mixed cultivation-income block
- standard error and response rate

## Why

The aim is to keep only the groups that can be defended more directly as environment-related if the review panel is being strict.
